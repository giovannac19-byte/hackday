# Hello, World

A sleek, softly feminine Hello World page: an italic serif headline in a frosted card on a blush background, with a deep plum look in dark mode.

It's a single `index.html` file with no build step. Open it in a browser, or host it with GitHub Pages.

## Publish with GitHub Pages

1. Go to the repository's **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Pick the `main` branch and the `/ (root)` folder, then select **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repo-name>/`.
